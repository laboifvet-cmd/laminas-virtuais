# Fonte oficial do código

A versão oficial está no GitHub, no repositório privado
`laboifvet-cmd/laminas-virtuais`, branch `main`. Trabalhe sempre num clone
atualizado (`git pull`) antes de alterar.

# Idioma

Código, comentários, documentação e mensagens de commit em português.

# Antes de enviar

Rode `python -m unittest discover -s tests`. Se falhar, pare e explique.

# Dados de pacientes

Nunca coloque no repositório lâminas, fotos ou fichas com número de caso,
nome de tutor, de animal ou de clínica. Lâminas convertidas ficam em
`amostras/`, que está fora do Git.

# Histórico das mudanças

Não marque o código com comentários do tipo "ACRESCENTADO", "ALTERADO" ou
número de versão. Explique o porquê no próprio comentário, quando ajudar, e
registre o histórico na mensagem do commit.
